Physical order belongs in code

  1. 01

    Fixed dependencies

    Repairs before paint. Paint before flooring. Cleaning last.

  2. 02

    Hard sequence guard

    If a cleaner reports done while repairs remain open, the system halts.

  3. 03

    Clear reason given

    The manager sees exactly which prior trade is still pending.

Software should not let a language model guess whether floors can be installed before paint is dry. Hard dependency rules reject out-of-order completions automatically.
